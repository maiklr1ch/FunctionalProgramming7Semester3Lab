# FunctionalProgramming7Semester3Lab
## Обробка тексту підручника з програмування: сортування слів за кількістю заданої літери (Haskell)

Репозиторій містить лабораторну роботу №3 з курсу «Функціональне програмування» за 7 семестр.

Програма читає текст підручника з файлу, розбирає його на абзаци, речення, слова, числа, розділові знаки й
інші символи та сортує всі слова тексту за зростанням кількості заданої літери в слові; слова з однаковою
кількістю розташовуються за абеткою. У сформованому тексті табуляції та послідовності пробілів замінено
одним пробілом.

## Запуск

```bash
cabal run textbook                           # файл буде запитано, за замовчуванням examples/textbook.txt
cabal run textbook -- шлях/до/підручника.txt
```

Залежності - лише `base` і `containers`, які постачаються разом із GHC. Файл читається в UTF-8, а якщо
не вдається - у Windows-1251.

## Меню

1. Завантажити інший файл
2. Показати текст (табуляції й послідовності пробілів замінено одним пробілом)
3. Показати речення
4. Розбір речення на лексеми
5. Розсортувати слова за кількістю заданої літери

Результат пунктів 2-5 можна зберегти у файл.

## Типи

| Тип | Що описує |
|-----|-----------|
| `Symbol` | символ |
| `Word` | слово: літери, цифри, `_`, апостроф і дефіс усередині (`об'єкт`, `будь-який`, `2-й`) |
| `Number` | число (`2010`, `3.14`, `1,5`) |
| `Punctuation` | розділовий знак: `. , ; : ! ? … - – — ( ) [ ] { } " ' « » „ “ ”` |
| `Element` | лексема: слово, число, розділовий знак, інший символ (`+ = < > * /` ...), пробіл, перенос рядка |
| `Sentence` | речення («пропозиція» в завданні) |
| `Paragraph` | абзац; абзаци розділяються порожнім рядком |
| `Text` | текст |

Класи типів:
- `Render` - формування тексту з будь-якого з цих типів. Будь-яка послідовність пробілів і табуляцій
  зберігається як один `ESpace` і виводиться одним пробілом;
- `Container` - лексеми речення, абзацу чи тексту; з них `wordsOf` бере слова;
- `Ord Word` - порівняння слів за українською абеткою.

## Розбір на речення

Речення закінчується знаком `.`, `!`, `?` або `…` (після нього можуть стояти закривні лапки чи дужки), якщо
далі йде пробіл або кінець тексту, а наступне слово не починається з малої літери. Тому «т. д.», «1990 р. і»,
«англ. pattern» речення не розривають, як і крапка без пробілу після неї (`System.out.println`, `3.14`).
Порожній рядок завершує і речення, і абзац.

## Сортування

- Кількість літери рахується без урахування регістру. Латинська `a` і кирилична `а` - різні літери,
  тому програма пише, з якого алфавіту задана літера.
- Абетка: цифри, кирилиця в порядку українського алфавіту (`г ґ д е є ж з и і ї й`), потім латиниця.
  Апостроф і дефіс при порівнянні пропускаються, як у словниках; при повному збігу мала літера йде
  перед великою.
- За замовчуванням кожне слово показується один раз із кількістю повторів у тексті (`Список` і `список` -
  одне слово, показується частіша форма). Можна вивести й усі входження.
